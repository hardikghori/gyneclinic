# Gyne Clinic App

Gyne Clinic App is a **full-stack web application** designed to manage gynecology clinic operations with an intuitive user interface and real-time data synchronization using **Firebase**. The app allows healthcare professionals to manage **patient records**, **appointments**, **prescriptions**, and **follow-ups** all in one place.

This project is built with modern **React.js**, **Firebase Firestore**, and **Firebase Authentication**, providing an optimized experience for clinic staff, doctors, and administrative personnel.

## Features

- **Patient Management**: 
  - Add new patients to the clinic system.
  - Search and select existing patients using an autocomplete feature.
  
- **Appointment Management**:
  - View and manage patient appointments.
  - Schedule new appointments.
  - Edit or cancel existing appointments.
  
- **Prescription & Follow-up**:
  - Generate prescriptions and track follow-up visits.
  - Provide follow-up checklists for patients.

- **Responsive UI**:
  - A clean and user-friendly interface optimized for desktop and mobile devices.

- **Real-time Sync**:
  - Firebase's Firestore ensures real-time data synchronization across all users.

---

## Tech Stack

- **Frontend**: 
  - **React.js**: A JavaScript library for building user interfaces, focusing on component-based architecture.
  - **React Hooks**: For state management and lifecycle handling.
  - **CSS/Styled Components**: For styling the application and making it responsive.
  
- **Backend**:
  - **Firebase Firestore**: A NoSQL database for storing and retrieving patient, appointment, and prescription data.
  - **Firebase Authentication**: For handling secure user authentication.

- **Deployment**:
  - **Firebase Hosting**: The app is deployed to Firebase for easy hosting with a fast and reliable content delivery network (CDN).
  
- **Others**:
  - **ESLint**: For maintaining code quality and enforcing best practices.
  - **Prettier**: For code formatting consistency.
